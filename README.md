# 🎮 Moan Memory

A chaotic twist on the classic **Simon Game**, built using **HTML**, **CSS**, and **JavaScript**. Instead of traditional tones, every button plays a hilariously cursed sound, turning a simple memory game into an unforgettable experience.

## 📖 About

**Moan Memory** is a browser-based memory game inspired by the classic Simon Game. Players must watch and remember an increasingly long sequence of colors, then repeat it perfectly to advance through the levels.

To make things... *less serious*, I replaced the standard sound effects with meme-worthy moan sounds—because sometimes the best projects come from terrible ideas that somehow work.

## 🚀 Features

* 🎮 Classic Simon Game mechanics
* 🧠 Increasing memory challenge every level
* 🔊 Custom sound effects for each button
* 🏆 High score saved using Local Storage
* ✨ Button animations and visual feedback
* ❌ Game over effects
* 📱 Keyboard and mobile support
* 📖 Built-in gameplay instructions
